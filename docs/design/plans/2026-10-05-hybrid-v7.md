# October 5, 2026: bounded hybrid V7 research plan

## Objective and constraints

Gather meaningful prospective evidence and test feasible statistical/ML methods
using the existing AWS host and home Mac. Preserve continuous paper operations,
complete historical research and truthful public reporting. The owner authorized
design followed by implementation, with no real money, no increased AWS charges,
no hardware/power modification and no sustained intensive local workload.

The current system has two distinct limitations: V7 source/static app delivery
is ahead of the September backend, and the same-volume deployment backup gate
has insufficient free capacity. A retrospective local score cannot solve either
by relabeling results. Research accounts remain economically separate.

## Execution design

1. Keep AWS as the sole ledger, settlement, operational publication and current
   runtime-data authority. Preserve all canonical timers and archive-only policy.
2. Install a six-hour, background, offline-first Mac worker after focused tests.
   Require AC/no native thermal warning/low host load/memory/disk headroom, one
   numerical thread, a shared non-overlap lock, half-core CPU pacing, 20-minute
   whole-run deadline, 10-minute observed CPU budget and 2 GiB sampled group RSS.
3. Reuse verified retained AWS research exports without cloud charges. Bind all
   outputs to original capture/source/input hashes and distinguish source-only
   reanalysis from fresh data. Preserve last success after failure.
4. Collect a separate small prospective weather shadow directly from approved
   free providers on the home's connection. Store append-only served/member
   evidence in ignored local state, initially SFO and bounded to four cities/eight
   requests per run. Expand only within the existing guard/API budgets.
5. Evaluate a proper-score location/scale baseline and shallow quantile boosting
   with chronological train/validation/test dates and original availability
   checks. Record experiments and losses; rejection is a valid result. No
   production-weight or trading-policy promotion is automatic.
6. Offer the actual full historical Strategy builder through verified complete
   paper/weather snapshots and APFS COW working clones. Bind source/config/input
   lineage, deny network, enforce the same lock/budget and produce staged cache
   plus private replay evidence. Preserve deployment/import gates.
7. Measure representative continuous AWS resource peaks and successful local
   replacement before selecting any smaller instance. Cloud costs may only
   decrease. No new EBS purchase, paid commitment, endpoint or extra service.

## Cost and hardware reasoning

The inspected Mac has 48 GiB memory, 16 logical CPUs, more than 400 GiB free
storage and FileVault enabled. These are October 5 observations. The local limits
are conservative operator budgets, not universal hardware safety constants.
Apple ties battery aging to temperature/charging pattern and recommends normal
ventilation; no charging, fan or power setting is changed. [Apple battery](https://support.apple.com/en-us/102338),
[Apple temperature](https://support.apple.com/en-us/102336).

EC2's running-time price is fixed, so lower CPU utilization alone is not claimed
as savings. The account's authenticated monthly forecast was $54.50, month-to-date
$8.00, September actual $52.81 at October 5, 23:04 PDT. The existing 31-GiB replica
and lagged billing prevent treating a published free-egress allowance as remaining
account capacity. Remote exports default off and require current-month verified
headroom plus worst-case reservation; full copies are never scheduled. [AWS
pricing](https://aws.amazon.com/ec2/pricing/on-demand/), [On-Demand
pricing](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/ec2-on-demand-instances.html).

`trading/tests/test_local_compute.py`. The worker includes audits, the small ML
evaluator and an optional distinct prospective collector; receipts bind all
artifacts and source/input identities. The full Strategy helper exists but
requires a complete verified weather snapshot and independent AWS import gates
before it can replace production rescore. Initial tests cover the failure and
provenance paths; a real bounded run and installed schedule must be checked by
private receipts. No local diagnostic or source-only merger is reported as a
completed backend deployment, AWS savings or profitable real-money strategy.

See `docs/local_compute.md` for operating instructions and remaining boundaries.
